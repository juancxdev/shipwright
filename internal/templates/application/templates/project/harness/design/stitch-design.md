## Design principles

- Generate high-fidelity UI, not low-fidelity wireframes.
- Preserve product scope and user goals from Shipwright artifacts.
- Create responsive mobile, tablet, and desktop variants.
- Prefer reusable components, clear hierarchy, accessible contrast, and realistic copy.
- Export screenshots and HTML evidence for every generated screen.

## Required outputs

- Stitch project/screen IDs.
- Screenshot exports.
- HTML exports.
- Design-to-code component map when frontend components exist.
